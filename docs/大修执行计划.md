## 总体策略

大修核心矛盾是 **R4 占 23 条意见且措辞最严厉**（"major revision"、"publication would require major revision"），其关注点集中在数学严谨性（B1 模型关系、active/silent neuron 处理、梯度稳定性证据）和验证协议透明度。策略上优先解决 R4 的数学/方法论问题（Day 1-3），同步处理 R1-R3 的实验补充（Day 2-4），最后集中做全文语言润色和格式统一（Day 5-6），Day 7 用于 Response Letter 和最终校验。

**优先级逻辑**: R4 数学修正 > 实验补充（消融/噪声/Jacobian） > 跨审稿人共性术语问题 > 格式/语言 > Response Letter

**合并原则**: 多位审稿人提出的相同问题、或同一技术点的不同角度意见，合并为单一任务统一回复，Response Letter 中也以合并形式回应，避免重复。

## Day 1: 数学公式严谨化 + 术语统一框架

### 任务 1.1: Active-spike mask 引入 — Eq.(6) 重写 + Eq.(11) 修正 (对应 R4-12, R4-14, R4-18)

**做什么**: 将 main.tex 的 Eq.(6)（`eq:b1_combined`）重写为 censored first-passage-time 模型，引入 active-spike mask，消除 T=T_max 边界歧义；同步修正 Eq.(11) output logit。

**怎么做**:
1. 在 main.tex 第 228-236 行，将 `eq:b1_combined` 改写为：
   - 第一个公式保留为 $\tilde{T}_i^{(n)}$（理论 threshold-crossing time）
   - 引入 active-spike mask $m_i^{(n)} = \mathbb{1}[\tilde{T}_i^{(n)} < T_{\max}^{(n)}]$
   - 第二个公式改为 $T_i^{(n)} = m_i^{(n)} \tilde{T}_i^{(n)} + (1 - m_i^{(n)}) T_{\max}^{(n)}$
2. 将"closed-form solution obtained by integrating"措辞改为"censored first-passage-time model"
3. Eq.(11)（`eq:out_logit`，第 270-273 行）加入 presynaptic mask：$L_i = \sum_j W_{ij}^{(L)} (T_{\min}^{(L)} - T_j^{(L-1)}) \cdot m_j^{(L-1)} + \epsilon \vartheta_i^{(L)}$

**为什么**: R4-12 明确指出"Eq.(6) is not entirely the closed-form integral of Eq.(5)"；R4-14 指出 T=T_max 边界歧义影响前向传播和梯度；R4-18 要求 output logit 包含 active-spike mask。这三条本质上是同一个数学问题（active/silent neuron 的形式化处理），是 R4 列在"most important issues"中的核心，不解决几乎必然拒稿。

### 任务 1.2: 数值保护 — Eq.(8) δ safeguard + INT8 量化修正 (对应 R4-13, R4-19)

**做什么**: 为 DF-TTFS 的 scaling factor 添加 δ 保护防止除零；修正 INT8 量化公式中 128 vs 127 的问题。

**怎么做**:

2. supplement.tex 第 414-421 行 `eq:quant_w`：将 128 改为 127，或添加说明解释为何使用 128。建议改为 127 以符合标准 symmetric INT8

**为什么**: 两条意见都关于数值稳健性。R4-13 指出 $V_{\max} = V_{\min}$ 时公式不稳定；R4-19 指出 128 不符合标准 INT8 量化惯例。都是工程实现中会实际触发的问题。
