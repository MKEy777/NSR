器件：`xc7z020clg400-2`

## 1. 总体判断

- 三个模块 `eegnet_top`、`pse_top`、`lds_kalman_top` 均已成功综合，说明 RTL 能生成综合网表。
- `100MHz / 10ns` 约束下三个模块均有 WNS < 0，因此第一版 RTL 不能直接宣称 100MHz 时序通过。
- 结合 EEG 低采样率场景，模块核不一定必须全部按 100MHz 单周期工作；低速模块时钟也可以是合理方案。
- 重新约束后，`eegnet_top@50MHz`、`pse_top@2MHz`、`lds_kalman_top@4MHz` 均 Timing PASS。
- 但从实际吞吐看，`pse_top@2MHz` 单核只适合单窗口功能测试；若要串行完成 `4x62=248` 次 PSE 并满足 1 秒级实时处理，吞吐不足，是当前最需要优化的模块。

## 5. 实际吞吐分析


| Module         | Scenario                     | ApproxCycles | Clock | TimePerUnit            | PracticalJudgement                                                  | Risk                                                                                                 |
| -------------- | ---------------------------- | ------------ | ----- | ---------------------- | ------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| eegnet_top     | One [4,8,9] EEGNet inference | 38600        | 50MHz | 0.77 ms / inference    | Enough for EEG feature-rate inference in current module-level test. | Uses dummy weights; this is throughput only, not model accuracy.                                     |
| pse_top        | One 200-sample PSE window    | 20500        | 2MHz  | 10.25 ms / PSE         | Enough for single-window functional testing.                        | If 4x62=248 PSE calls must finish within 1s, one serial core takes about 2.54s, so it is not enough. |
| lds_kalman_top | 288 lanes x 3 test steps     | 864          | 4MHz  | 0.216 ms / 864 outputs | Likely enough; even 288 lanes x 60 steps is about 4.32 ms at 4MHz.  | The divider path is slow, but low-frequency module clock still meets timing.                         |

关键结论：EEGNet 50MHz 和 LDS 4MHz 对当前模块级测试通常够用；PSE 2MHz 对单次 PSE 功能测试够用，但若要实时处理 `4x62=248` 个 PSE 窗口，单核串行约需 2.54s，不满足 1s 级实时处理。

## 6. 优化可能性


| Module         | MainCause                                                                                                  | 100MHzFix                                                                                                                       | Priority |
| -------------- | ---------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- | -------- |
| eegnet_top     | Intermediate feature arrays are implemented as many registers and large mux paths.                         | Store feature maps in BRAM/distributed RAM, add pipeline registers around MAC and memory read paths.                            | Medium   |
| pse_top        | Direct DFT-MAC plus log/division creates very long combinational paths; throughput is also the bottleneck. | Use FFT IP or pipelined FFT, replace division with multicycle/pipelined divider or reciprocal LUT, consider multiple PSE cores. | High     |
| lds_kalman_top | Kalman gain division is implemented as a combinational division path.                                      | Replace / with iterative divider, pipelined divider, or reciprocal LUT plus multiply.                                           | Medium   |

## 7. 建议交付口径

可以对甲方说明：当前第一版三个模块已经分别完成综合并生成资源报告；在 100MHz 下时序尚未收敛；结合 EEG 低采样率场景，采用合理低速模块时钟后均可 Timing PASS。若后续要求全量 PSE 实时处理或所有模块 100MHz 通过，需要进一步做 PSE/除法器/存储结构的 RTL 优化。
